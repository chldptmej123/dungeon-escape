# Doomlike Dungeon — Godot 3D 시작 프로젝트

Godot 4용 1인칭 던전 액션 프로토타입입니다. macOS와 Windows에서 같은 프로젝트를 열 수 있습니다.

1. Godot Project Manager에서 **Import**를 클릭합니다.
2. 이 폴더의 `project.godot`을 선택합니다.
3. 프로젝트를 연 뒤 `F6`을 누릅니다.
4. 게임 화면을 클릭해 마우스를 잡고 `WASD`로 이동합니다.

조작: `WASD` 이동, 마우스 시점, 클릭 칼 공격, `Space` 점프, `Esc` 마우스 풀기, 다시 클릭하면 마우스 잡기. 유령은 벽 충돌을 사용하므로 벽을 통과하지 않습니다.

목표: 던전을 탐험하고 적을 처치하세요. 열쇠·문·포탈 같은 목표 아이템은 없습니다.
